# Power BI Dashboard Documentation

## Herbal Remedies Field Survey Dashboard

### Project Overview

The Herbal Remedies Field Survey Dashboard was developed in Power BI to transform cleaned survey data into an interactive analytical dashboard.

The dashboard provides a concise view of herbal remedy usage, respondent demographics, perceived effectiveness, usage frequency, recommendations, and reported side effects.

---

## Dashboard Purpose

The dashboard was designed to support:

- Survey data exploration
- Respondent profiling
- Herbal remedy usage analysis
- Perceived effectiveness assessment
- Usage frequency analysis
- Reported side-effect monitoring
- Interactive filtering
- Data-driven reporting

---
