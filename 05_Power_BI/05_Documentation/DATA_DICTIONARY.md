## Field Definitions

| Field Name | Data Type | Description |
|---|---|---|
| RespondentID | Integer | Unique identifier assigned to each survey respondent. |
| Gender | Categorical | Gender of the respondent. |
| AgeGroup | Categorical | Age category of the respondent. |
| Location | Categorical | Residential location classification of the respondent. |
| UsesHerbalRemedies | Categorical | Indicates whether the respondent uses herbal remedies. |
| HerbsUsed | Categorical | Type or combination of herbal materials used by the respondent. |
| UsageFrequency | Categorical | Frequency at which the respondent uses herbal remedies. |
| ReasonForUse | Categorical | Reported reason or reasons for using herbal remedies. |
| HerbSource | Categorical | Main source from which the respondent obtains herbal remedies. |
| IsEffective | Categorical | Indicates whether the respondent considers herbal remedies effective. |
| EffectivenessLevel | Categorical | Respondent's reported level of perceived effectiveness. |
| HasSideEffects | Categorical | Indicates whether the respondent reported side effects from herbal remedy use. |
| CombineWithHospitalMedicine | Categorical | Indicates whether the respondent combines herbal remedies with hospital medicine. |
| RecommendToOthers | Categorical | Indicates whether the respondent would recommend herbal remedies to others. |
