# Herbal Remedies Survey Project

## Project Overview

The Herbal Remedies Survey Project is a data collection, data preparation, analysis, and visualization project focused on understanding the use of herbal remedies among survey respondents.

The project combined digital data collection, structured data preparation, analytical processing, and data visualization to transform raw survey responses into meaningful findings and practical insights.

## Project Purpose

The purpose of the project was to examine:

- The use of herbal remedies among respondents.
- Common reasons for using herbal remedies.
- Respondents' perceptions of effectiveness.
- Reported experiences and side effects.
- Willingness to recommend herbal remedies.
- Patterns that can support safer and more informed use.

## Data Collection

Data was collected using multiple digital data-collection platforms:

- KoboToolbox
- CommCare
- Google Forms

The multi-platform approach provided an opportunity to consolidate and validate survey responses before analysis.

## Data Preparation

The collected data was reviewed and prepared for analysis through:

- Data quality checks.
- Cleaning of inconsistent entries.
- Standardization of variables.
- Removal of unnecessary fields.
- Structuring of the final analytical dataset.
- Cross-checking of results across data sources.

## Data Analysis

The project used:

- Microsoft Excel for data preparation, exploration, and dashboard development.
- SQL for data integration, querying, and analytical validation.
- Power BI for interactive visualization and dashboard reporting.

## Data Visualization

The analysis was transformed into visual outputs designed to communicate key findings clearly.

The project includes:

- Excel dashboard.
- Power BI dashboard.
- Analytical charts.
- Presentation of key findings.
- Recommendations and conclusion.

## Final Analytical Dataset

The final analytical dataset contains:

**60 respondents**

The dataset was prepared as the basis for the final analysis and reporting.
